# Exploring NVIDIA SkillSpector

This repository serves as a workspace for exploring, testing, and evaluating **NVIDIA SkillSpector**, a powerful security scanning tool designed to detect vulnerabilities, malicious patterns, and security risks in AI agent skills before installation.

## Repository Contents

- **`skillspector/`**
  The core source code of NVIDIA SkillSpector. This tool uses both fast static analysis and optional LLM semantic evaluation to analyze skills for 64 vulnerability patterns across 16 categories.

- **`test_skill/`**
  A mock skill directory containing deliberately vulnerable code (`malicious.py`). This is used to test and demonstrate SkillSpector's detection capabilities across various risk categories like arbitrary code execution and exfiltration.

- **`mcp-servers/`**
  A directory containing Model Context Protocol (MCP) servers, notably a filesystem server, which is also used as a test target for SkillSpector scanning.

- **`report.md`**
  A sample SkillSpector security report generated by scanning the `test_skill` directory. It demonstrates how SkillSpector formats its findings, severity scores, and remediation advice.

- **`filesystem_mcp_report.md`**
  A sample SkillSpector security report generated by scanning the `mcp-servers/src/filesystem` directory.

## Getting Started

To explore SkillSpector's capabilities:

1. Navigate to the `skillspector/` directory to view the scanner's source code and documentation.
2. Review the `report.md` and `filesystem_mcp_report.md` files to see what the generated security reports look like.
3. Inspect `test_skill/malicious.py` to see the types of patterns (like `subprocess`, `eval()`, etc.) that triggered the high-severity alerts in `report.md`.
